## Junior Year - 1st Semester

During the 1st semester of my junior year in information systems, my team and I were tasked with building a mental health website that focused on providing resources and support for students. This project was part of our Integrated Experience (Intex) course, which focused on real-world application of information systems concepts.

We worked on building a comprehensive mental health platform with integrated data analysis capabilities based on datasets given to us beforehand. The project involved multiple components including frontend development, backend integration, data analysis, and cloud deployment.

## Project Overview

Our team developed a full-stack web application that included:

- **Frontend**: Modern, responsive web interface built with JavaScript, HTML5, and CSS3
- **Backend**: RESTful API and server-side logic using Node.js and Express.js
- **Database**: PostgreSQL database for storing survey responses and user data
- **Data Analysis**: Python-based analysis using pandas, seaborn, and matplotlib
- **Data Visualization**: Integrated Tableau dashboards for mental health analytics
- **Survey System**: Custom survey tool with real-time data collection

## Technical Implementation

The project began with comprehensive planning and architecture design, where we established a clear vision for the user experience and technical requirements. This collaborative development process helped us create a robust and scalable solution.

[View Project Presentation Slides](https://docs.google.com/presentation/d/1EL-qOMlY1QoDy-lYeeDrx0bx5QCw8lqszRYoyHwlAis/edit?slide=id.p#slide=id.p)

## Data Analysis Components

### Python Data Processing

We implemented a comprehensive data analysis system using Python to process and analyze mental health datasets:

- **Data Cleaning**: Prepared and cleaned large datasets using pandas
- **Statistical Analysis**: Applied statistical methods to understand mental health trends
- **Data Visualization**: Created insightful charts and graphs using seaborn and matplotlib
- **Pattern Recognition**: Identified key correlations and insights in mental health data

[View Data Analysis Notebook](https://colab.research.google.com/drive/12Pnh7F3gMJjaKOuZhq0xPxQQAaHn8hjO)

### Survey System

As part of our data collection measures, we developed a custom survey tool that connected directly to a PostgreSQL database for real-time data collection. This component helped ensure comprehensive data gathering and secure storage of mental health insights.

## Cloud Infrastructure

The project was deployed on AWS using:

- **Elastic Beanstalk**: For automated deployment and scaling
- **Route 53**: For domain management and DNS routing
- **EC2 Instances**: For reliable server hosting and performance
- **RDS**: For managed PostgreSQL database services

## Junior Year - 2nd Semester

During the 2nd semester of my junior year in information systems, my team and I were tasked with building a shopping website for a lego influencer Aurora. This project was part of our Integrated Experience (Intex) course, which focused on real-world application of information systems concepts.

We worked on building a comprehensive e-commerce platform with a machine learning recommendation engine based on data given to us beforehand. The project involved multiple components including frontend development, backend integration, data analysis, and machine learning implementation.

## Project Overview

Our team developed a full-stack web application that included:

- **Frontend**: Modern, responsive web interface built with React
- **Backend**: RESTful API and database management
- **Machine Learning**: Recommendation engine for product suggestions
- **Data Analysis**: Processing and analysis of user behavior data
- **E-commerce Features**: Shopping cart, user authentication, and payment integration
